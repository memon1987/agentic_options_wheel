## Design decisions (made)

- **Classify with `strict_option_type`; root with `parse_option_symbol(...)['underlying']`**
  (the existing `_extract_underlying_from_option_symbol` already does the latter). At all
  three sites.
- **Unclassifiable symbols are counted, not dropped silently:** a position whose
  `strict_option_type` is `None` increments a new `alpaca_option_counts[underlying]['unclassified']`
  bucket and emits one `logger.warning(..., event_type="reconcile_unclassifiable_option", symbol=…)`
  per symbol per run. Reconcile must never guess a leg (the FC-045/FC-053 posture), and must
  never make an adjusted contract vanish from the counts.
- **Strike on call-away:** parse with `parse_option_symbol(...)['strike_price']`; drop the
  `[-8:]` slice.
- **`reconcile_orphaned`:** `strict_option_type(symbol) == 'call'` and
  `parse_option_symbol(symbol)['underlying']`; unclassifiable symbols are listed in a separate
  `unclassifiable` detail field on the existing `warn` (the `risk_unclassifiable_option` check
  already covers alerting — do not add a second event).
- **Scanner ride-along (from the S3 review):** `OptionsScanner._log_existing_position_skip`
  gets a third `reason`, `unparseable_position`, emitted from `_has_existing_position` when
  `_option_position_matches` returned `True` **because** the symbol was unparseable (today
  both paths say `option_position`). Implement by having `_option_position_matches` return a
  small enum/str (`'match' | 'no_match' | 'unparseable'`) instead of `bool`; one call site.
- **A grep gate, so this is the last such PR:** `tests/test_no_occ_substring.py` walks
  `src/` and `tools/testing/` for the patterns `'P' in `, `'C' in `, `"P" in `, `"C" in `,
  `[-9]`, `[-8:]` applied to a variable whose name contains `sym` and fails naming file:line.
  Allow-list exactly one site: `src/utils/option_symbols.py`'s documented last-resort
  fallback (match by file path + a `# occ-substring-allowed` marker comment on that line).
  Ad-hoc scripts under `tools/testing/debug_*.py` / `detailed_*.py` are either fixed in this
  PR (trivial) or moved out of the walked tree — builder's choice, state which.

  only the label changes).
