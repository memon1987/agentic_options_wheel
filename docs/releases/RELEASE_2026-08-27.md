## Key Decisions & Rationale
- **Compressed shadow (operator override of the shadow week):** on paper, the week's irreplaceable value reduces to exercising each job type + the two drills; money risk ≈ 0 and the wheel's dataset is protected structurally. Drills ran Monday morning; first lots bought same day.
- **14 DTE over widening the delta band or lowering the premium floor:** three days of live data showed the [0.15, 0.25] band × $0.30 floor intersection is **empty** on a ≤7-DTE chain at current IV (UNH zero-qualified while trading *above* basis). Extending DTE raises premium at unchanged delta — the most targeted lever. Ranking math verified: week-1 stays preferred whenever it qualifies, so 14 is a true fallback.
- **Band-cliff accepted in writing (PR #91 review):** `dte_bands` are day-of-life-calibrated to 7-DTE entry; a 14-DTE position runs 0.50 for week one then hits the 0.35 band at DTE 7 → likely ~day-7 exits at ≥35% gain. Accepted because it's profit-taking-early (not risk-adding); retune from live exit data.
- **DD-7 deleted, not disabled:** once no writer can be constructed without a dataset, the guard has no failure mode left to guard; a tautological control is a defect per config discipline.
- **Declined the crude build-freshness alert:** Cloud Monitoring absence windows cap at ~24h vs. this repo's bursty push cadence — it would cry wolf weekly. FC-081's proper scheduled-comparison fix stays open instead.

## Discoveries
- **A failed build's only ERROR-severity log entry is the audit-log CreateBuild completion** — the `cloudbuild` logName stays INFO on failure. Scope build alerts by methodName exclusion, never logName.
- **The CC service's `/run` writes no executions row on an empty blob** (early-return before the writer) — absence of `/run` rows is normal, not a failure; the request logs are the heartbeat.
- **History ingests write *completed* days** — today's equity/stock rows land tomorrow. R4-style verification must account for it.
- **Two main builds started 3 seconds apart** during the session — live evidence for FC-084 (all three canary chains identify "my canary" as newest-revision and promote `--to-latest`).
- Day-of-week arithmetic burned the session once (listener armed for the wrong Monday) — verify against a known anchor date.
